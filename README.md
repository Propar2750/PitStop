# F1 Pitstop Prediction

## Requirements

- Python 3.9+
- The Python packages listed in `requirements.txt`:
  - `numpy`, `pandas`, `scipy`
  - `scikit-learn`, `lightgbm`
  - `matplotlib`, `seaborn`
  - `kagglehub` (for downloading the dataset)
  - `jupyter` (to run `training.ipynb`)

You will also need a [Kaggle](https://www.kaggle.com/) account to download the competition data.

### Installing the requirements

It is recommended to use a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate        # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Or, if you prefer conda:

```bash
conda create -n f1-pitstop python=3.11 -y
conda activate f1-pitstop
pip install -r requirements.txt
```

## Data Files

The following data files are **not included** in this repository because they are too large:

- `train.csv`
- `test.csv`
- `sample_submission.csv`
- `submission.csv`

You must create/download these locally before running the notebook.

### Downloading the data

The dataset comes from the Kaggle competition `playground-series-s6e5`. Run:

```bash
python download.py
```

This uses `kagglehub` to fetch the competition files. After download, copy `train.csv`, `test.csv`, and `sample_submission.csv` into the project root. `submission.csv` is generated by running `training.ipynb`.

To note: Kagglehub doesnt download directly into this directly, you will need to check where it downloaded and get the data from there. 

## Baseline

The **baseline** is the fixed reference setup all trials are compared against. A trial is "baseline" only if it matches every item below; deviating in any item means the trial belongs in `trials.csv` with the change described in the `features`/`algorithm`/`notes` columns.

**Task**
- Binary classification of `PitNextLap` (does the driver pit on the next lap?).
- Evaluation: ROC AUC, with average precision and log loss reported alongside.

**Data**
- `train.csv` and `test.csv` from the Kaggle competition `playground-series-s6e5`, used as-is (no extra/external data, no row filtering).
- ID column: `id`. Target: `PitNextLap`.

**Features (raw columns kept; no engineered features)**
- Numeric: `Year`, `PitStop`, `Stint`, `TyreLife`, `Position`, `LapTime (s)`, `LapTime_Delta`, `Cumulative_Degradation`, `RaceProgress`, `Position_Change`.
- Categorical (passed to LightGBM as `category` dtype): `Driver`, `Compound`, `Race`.
- Dropped: `id`, `PitNextLap` (target), `LapNumber` (replaced by `RaceProgress`).
- No imputation, no scaling, no target encoding, no interaction terms.

**Cross-validation**
- `StratifiedGroupKFold`, `n_splits=5`, `shuffle=True`, `random_state=42`.
- Group key: `Race + "_" + Year + "_" + Driver` so a single stint cannot leak across folds.

**Model — LightGBM**

| Param | Value |
|---|---|
| `objective` | `binary` |
| `metric` | `auc` |
| `learning_rate` | `0.05` |
| `num_leaves` | `63` |
| `feature_fraction` | `0.9` |
| `bagging_fraction` | `0.9` |
| `bagging_freq` | `5` |
| `min_data_in_leaf` | `100` |
| `seed` | `42` |
| `num_boost_round` | `3000` |
| early stopping | `100` rounds on the validation fold |

**Inference**
- Per fold: predict OOF on the validation indices, predict on `test` and divide by `N_SPLITS`.
- Final test prediction = mean of the 5 fold predictions, written to `submission.csv` (column `PitNextLap`).

**Reference score**
- Baseline OOF AUC: `0.9409` (AP `0.7874`, log loss `0.2421`). Trial deltas in `trials.csv` are measured against this.

## Trial Log

Each experiment is logged as a row in `trials.csv`. The baseline above is the reference; a trial entry should describe how it differs (new feature, different model, hyperparam sweep, etc.).

Columns:

- `trial` — incrementing integer (1-based)
- `date` — `YYYY-MM-DD`
- `commit` — short git SHA the trial corresponds to
- `algorithm` — model name + key hyperparams (e.g. `LightGBM (lr=0.05, leaves=63)`)
- `features` — short description of the feature set (e.g. `baseline`, `baseline + IsLateRace`)
- `cv_auc` — 5-fold OOF AUC under the baseline CV scheme (blank if not computed)
- `lb` — Kaggle public leaderboard score (blank if not submitted)
- `notes` — free-text; quote with `"..."` if it contains commas
